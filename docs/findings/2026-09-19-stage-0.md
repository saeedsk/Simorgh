## What broke and was fixed on the way

- Deleting `src/` broke four code sites that still named it (planning's source roots, a verification invariant, Guardian's protected list) and ten test fixtures that used `src/` paths as example subjects. Two tests pinned "a step naming `src/` is kept"; they now pin the opposite.
- Deleting the blueprint broke three integration tests that read `docs/blueprint/subsystems/09-guardian.md` through the real `read_file` tool; they read `docs/ARCHITECTURE.md` now. First attempt used `simorgh/guardian/CONTRACT.md`, which is under a protected path and was correctly denied: the gate works.
- The boot test pinned Learning as the one subsystem allowed to be `degraded` (its PatchPipeline was unreachable); with the pipeline retired every subsystem boots healthy and the exemption is gone.
- `tests/simorgh/voice/test_session.py::TestTenTurns` and `test_local_multi_worker_crash_resume.py` each failed once under xdist and passed alone: timing-flaky, listed for the `slow` marker and a fake clock.

## Decisions recorded

- The full suite is the bless gate and a nightly job; day to day is the module tier (`docs/testing.md`).
- Module locks are a committed file; two agents claiming the same module collide on the push (`docs/AGENTS.md`).
- `[guardian.physical] auto_approve` is the only switch that loosens the house; `SIMORGH_GUARDIAN_AUTO_APPROVE` covers code only.
- Untyped chat turns are not learning outcomes.
- A topic with one side fails the build; the allow-list must name the stage that connects it.
- The strong tier (`together_strong`, GLM-5.3) is capped at $3/day and used for decompose, review, verify and retries.
- The old ledger is kept at `~/.simorgh/ledger.pre-rebirth-2026-09-18` until nothing is missed, then deleted.
